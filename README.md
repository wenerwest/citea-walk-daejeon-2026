# CiTEA Walk in Junggu, Daejeon 2026 운영 가이드

로그인·설치 없이 사용하는 한국어 / English / 대만 번체 / 중국 간체 도시 탐방 가이드입니다. 별도 서버, 유료 API, npm 설치 없이 동작하는 정적 웹사이트이며, GitHub 무료 기본 주소로 배포할 수 있습니다.

공개 사이트: [CiTEA Walk 바로 열기](https://wenerwest.github.io/citea-walk-daejeon-2026/)

소스 저장소: [wenerwest/citea-walk-daejeon-2026](https://github.com/wenerwest/citea-walk-daejeon-2026)

메인 QR은 `public/qr/main.png` 및 `main.svg`입니다. 언어별 메인과 장소별 QR을 포함해 총 37개 연결 주소가 제공됩니다.

## 먼저 확인할 콘텐츠

제공된 수정 일정표 1을 대조해 11월 7–10일의 44개 항목을 한국어·대만 번체·중국 간체로 반영했습니다. 표의 병합 셀 시작 시각을 사용했으며 종료 시각은 만들지 않았습니다. 11월 7일 13:00 카페 폴레 만남을 표시하고, 원본에 없는 상세 주소·예약·집합 지점은 확인 대상으로 남겼습니다. 상하이행은 원본의 ‘2시’(오전·오후 미표기)를 유지합니다. 원본 PDF 파일은 공개 저장소에 올리지 않았으며, 일정 데이터만 반영했습니다. 실제 MP3는 여전히 입력이 필요합니다. 운영진 연락처와 긴급안내는 요청에 따라 화면에서 삭제했습니다. 확인되지 않은 역사적 연결, 2026년 행사·시설 운영 정보는 화면의 확인 안내와 출처를 검토한 뒤 확정해 주세요.

## 실행과 배포 파일 만들기

Node.js 22 이상을 설치한 뒤 이 README가 있는 폴더에서 실행합니다.

```sh
node scripts/dev.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 휴대전화로 같은 Wi-Fi에서 확인하려면 `node scripts/dev.mjs --host 0.0.0.0`으로 실행한 뒤 컴퓨터의 실제 LAN 주소로 접속합니다. 오프라인 저장 기능은 HTTPS 배포 주소 또는 localhost에서 확인하세요.

```sh
node scripts/build.mjs
node scripts/dev.mjs --dist --port 4174
```

`dist/`가 배포용 결과입니다. 빌드는 JSON 문법, 4개 언어 텍스트, 장소 ID 중복, 일정의 장소 참조와 시간 형식, 등록한 로컬 오디오·사진 파일 존재 여부를 검사합니다. 배포 파일의 JavaScript와 CSS 주소에는 콘텐츠 기반 버전을 자동으로 붙여 업데이트 후 이전 파일이 캐시에 남는 것을 줄입니다. 앱과 자료를 변경한 뒤에는 다시 빌드하세요. `dist/`를 직접 수정하면 다음 빌드에서 덮어씁니다.

## 운영자가 수정하는 파일

| 파일 | 수정 내용 |
| --- | --- |
| `public/data/event.json` | 행사 설명, `dates`별 일정, `notices`, 준비물 `checklist` |
| `public/data/places.json` | 장소 이름·소개·배경·방문 목적·주소·지도·출처·오디오 |
| `public/data/locale.json` | 메뉴, 버튼 등 화면 공통 문구 |
| `public/data/site.json` | 실제 공개 주소 `publicUrl` 등 사이트 설정 |
| `public/audio/ko/`, `en/`, `tw/`, `cn/` | 언어별 실제 MP3 파일 |
| `public/assets/` | 사용 허락을 확보한 사진과 안내 이미지 |

텍스트의 언어 키는 `ko`, `en`, `tw`, `cn`입니다. 예: `{"ko":"집합 안내","en":"Meeting information","tw":"集合資訊","cn":"集合信息"}`. 장소의 `id`는 링크와 QR에 쓰이므로 공개 후에는 유지하세요. 주소와 시설 운영시간은 공식 출처를 확인하고, `sources`에 출처 URL을 남깁니다. 불명확한 항목은 `null`과 확인 안내를 유지합니다.

### 일정 등록

`event.json`의 해당 `dates` 항목에서 `items`에 원본 PDF와 일치하는 항목만 추가합니다. 날짜 ID는 `2026-11-07`, `2026-11-08`, `2026-11-09`, `2026-11-10`입니다.

```json
{
  "time": "09:00",
  "title": { "ko": "원본 프로그램명", "en": "Original programme title", "tw": "原始活動名稱", "cn": "原始活动名称" },
  "placeId": "naraegwan",
  "description": { "ko": "원본 확인 후 입력", "en": "Enter after checking the original", "tw": "核對原始資料後填寫", "cn": "核对原始资料后填写" }
}
```

위 시간은 **형식 예시이며 실제 행사 일정이 아닙니다**. 원본을 대조해 시간·장소·내용을 모두 바꾸세요. 시간 범위는 `09:00–10:00` 형식을 사용할 수 있습니다. `placeId`는 `places.json`의 실제 ID와 일치해야 합니다. 원본은 운영용 자료로 보관하고, 일정 변경 시 해당 `items`와 공지·`scheduleRevision`을 함께 수정합니다. 현재 `scheduleSource`는 `null`이며, 공개용으로 승인된 문서 URL이 있을 때만 연결합니다.

일정 항목의 `meetingPoint`에는 네 언어 집합 안내를 넣을 수 있습니다. 장소 자체의 집합 지점은 `places.json`의 `meetingPoint`로 관리합니다.

일정 항목에 `mapUrl`을 넣으면 지도 검색어와 장소 기본 링크보다 해당 HTTPS 주소를 우선합니다. 항목별 사진은 `image` 객체(`src`, 4개 언어 `alt`, `width`, `height`)로 지정하며, 없으면 연결된 장소의 대표 사진을 사용합니다. 현재 11/7 13:00 카페 폴레폴레는 제공된 NAVER 공유 링크를, 18:00 일몰 감상은 `assets/supplied/bomunsan-sunset.webp`를 사용합니다.

### 공지

`notices`의 `title`과 `body`를 네 언어로 수정합니다. 집합 장소와 시간은 원본 일정과 현장 운영을 확인한 뒤 입력하세요. 연락처와 긴급안내 영역은 표시하지 않습니다.

### 오디오 추가

1. 저작권·초상권을 확보한 실제 MP3를 준비합니다. 경량 음성 파일을 권장하며, 한 파일이 GitHub의 파일 업로드 한도를 넘지 않도록 합니다.
2. 예를 들어 한국어 나래관 파일을 `public/audio/ko/naraegwan.mp3`로 저장합니다.
3. 해당 장소의 `audio.ko`를 아래처럼 바꿉니다. 번체는 `audio.tw`, 간체는 `audio.cn`에 각각 별도 파일을 연결합니다.
4. `node scripts/build.mjs`로 확인하고 다시 배포합니다.

```json
"audio": {
  "ko": { "src": "audio/ko/naraegwan.mp3", "title": "대전전통나래관 안내" },
  "en": null,
  "tw": null,
  "cn": null
}
```

파일 경로 앞에 `/`를 붙이지 마세요. 그래야 `계정.github.io/저장소/` 주소에서도 작동합니다. 파일이 없는 언어는 `null`을 유지합니다. 녹음을 교체할 때는 `naraegwan-v2.mp3`처럼 파일명을 바꾸고 `src`도 갱신하면 이미 저장된 이전 녹음과 구별할 수 있습니다. 각 기기에서 사용자가 재생 버튼을 눌러 시작하며, 다른 참가자 기기와 동기화하지 않습니다. 화면 이동 중에는 사이트 하단 플레이어가 재생을 유지합니다. 외부 지도 열기, 브라우저 탭 종료, OS의 메모리·배터리 정책에 따른 지속 재생은 기기와 브라우저에 따라 달라집니다.

오디오의 기기 저장 기능은 지원 브라우저에서 사용할 수 있습니다. 행사 전에 파일을 저장한 뒤 비행기 모드로 확인하세요. 브라우저 저장소는 기기 용량이나 브라우저 정책에 따라 삭제될 수 있어, 다운로드 파일도 개인 기기에 보관하는 것을 권장합니다. 실제 MP3를 등록한 뒤 Android Chrome 및 iPhone Safari의 재생·탐색·속도·잠금화면·오프라인 동작을 반드시 확인하세요.

### 지도·사진

`naverQuery`는 실제 한글 장소명과 확인된 주소를 포함한 NAVER 지도 검색어입니다. 정확한 공식 장소 링크를 확보하면 `naverUrl`에 넣고, 확인된 길찾기 링크는 `directionsUrl`에 넣습니다. 검색 결과는 지도에서 동일 장소인지 최종 확인하세요. 좌표나 주소를 추측해 입력하지 마세요. `verified`는 자료 확인 상태를 뜻하며, 행사 방문시간이나 예약 확정을 뜻하지 않습니다. `meetingPoint`도 운영진 확정 전에는 `null`로 둡니다.

사진 파일은 용량을 줄인 WebP/JPEG 등을 사용하고 `places.json`의 `image.src`, `image.alt`, `image.source`, `image.credit`를 함께 갱신합니다. 홈 사진은 `site.json`의 `hero`에서 수정합니다. 첨부된 장소 이미지 9개는 `public/assets/supplied/`에 WebP로 최적화하여 연결했습니다. 기관 로고 2개는 `site.json`의 `footerLogos`로 관리합니다. 우암사적공원 사진(Jo, CC BY 2.0)의 출처·라이선스 링크는 상세 페이지에서 확인할 수 있습니다. 현재 대표 이미지는 우암사적공원의 봄 자료사진이며, 화면에 촬영 계절과 출처·라이선스를 표시합니다. 사진이 없는 장소는 `사진 준비 중`으로 표시하므로 행사 전에 사용 허락을 확보한 실제 장소 사진을 추가할 수 있습니다.

### 색상·폰트·반응형 화면

브라우저 파비콘은 제공된 보행 그림을 사용합니다. `public/assets/icons/`의 16·32·48px PNG와 ICO는 브라우저 탭용, 180px PNG는 iPhone 홈 화면용, 192·512px PNG는 웹 앱 아이콘입니다. 그림 전체가 보이도록 정사각형 배경 여백을 더했으며, `index.html`과 `public/manifest.webmanifest`에서 연결합니다. 아이콘·매니페스트 링크에도 빌드 버전을 붙여 업데이트 시 캐시를 갱신합니다.

`styles.css` 상단의 색상 변수로 기본 배경 `#F9FBF8`, 본문 `#2B302A`, 주요 버튼 `#1C3A27`, 라임 강조색 `#75F014`를 관리합니다. 라임은 작은 본문 글씨 대신 선택 표시·진행 막대 등에 사용합니다. 상단·펼침 메뉴는 20px, 섹션 안내·장소 분류·이동 링크와 주요 버튼은 16px입니다. 1200px 이하에서는 펼침 메뉴로 전환합니다. PC에서는 모든 메뉴를 바로 표시하고, 공간이 부족하면 두 줄로 배치해 큰 글씨가 겹치지 않게 합니다. 모바일 본문은 14–15px 이상, 주요 버튼은 높이 44px 이상이며, 480px 이하에서는 장소 카드를 한 열로 보여 줍니다.

영문·숫자는 Poppins, 한글은 Pretendard Variable을 사용합니다. 번체·간체 화면은 해당 지역의 시스템 중국어 글꼴을 우선합니다. 폰트는 `public/assets/fonts/`에 저장되어 외부 폰트 서비스 호출 없이 제공됩니다. `fonts.css`는 필요한 글꼴만 불러오고, 다운로드 중에는 시스템 글꼴을 먼저 표시합니다. 원본 라이선스와 출처는 같은 폴더의 `*-OFL.txt`, `SOURCES.md`에 보관합니다. 폰트 파일을 교체할 때 라이선스도 함께 유지하세요.

### 준비물 카테고리·추천 앱

준비물 카테고리는 모바일과 데스크톱 모두 굵은 20px, 항목명은 18px, 설명은 16px입니다. `event.json`의 `checklist`에서 각 항목을 수정합니다. 추천 앱 항목의 `app.icon`에는 `public/` 기준 아이콘 경로, `app.downloads.android`와 `app.downloads.ios`에는 공식 스토어 주소를 넣습니다. `app.paragraphs`는 언어별 소개 단락, `app.sources`는 공식 출처 목록입니다. 아이콘은 `public/assets/apps/`에 보관하며 앱 다운로드 버튼은 체크박스 영역 밖에 있어 링크를 눌러도 체크 상태가 바뀌지 않습니다.

타슈 소개는 대전시 공식 자료를 대조해 수상 정보를 **2015년 한국교통연구원 ‘지속가능 교통대상’**으로 표기했습니다. 기존 해외 휴대전화 번호의 인증·이용 가능 여부 확인 안내는 유지합니다. 스토어 링크는 외부 서비스이므로 인터넷 연결이 필요합니다.

## GitHub Pages 무료 배포

이 폴더의 **내용 전체**를 공개 GitHub 저장소의 루트에 올립니다. `.github/workflows/pages.yml`도 포함해야 합니다. GitHub Free의 공개 저장소에서 Pages를 사용할 수 있으며, 별도 도메인을 살 필요가 없습니다. 절차와 워크플로는 [GitHub Pages 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)를 기준으로 구성했습니다.

1. GitHub에서 공개 저장소를 만들고, 기본 브랜치를 `main`으로 둡니다.
2. 이 폴더 내용을 커밋·푸시합니다. `dist/`는 자동으로 생성되므로 올리지 않아도 됩니다.
3. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
4. **Actions**에서 `Deploy CiTEA Walk to GitHub Pages`의 성공을 확인합니다. 기본 브랜치가 다르면 워크플로의 `branches` 값을 바꿉니다.
5. Pages가 표시하는 실제 HTTPS 주소를 엽니다. 프로젝트 저장소의 주소는 대개 `https://계정.github.io/저장소/` 형식입니다. 표시된 실제 주소를 사용하세요.
6. `public/data/site.json`의 `publicUrl`에 그 주소를 입력하고 QR을 생성한 뒤 다시 커밋·푸시합니다.

워크플로는 `checkout@v6`, `setup-node@v7`, `configure-pages@v5`, `upload-pages-artifact@v4`, `deploy-pages@v4`를 사용하며 npm 의존성을 설치하지 않습니다. GitHub Actions의 `github-pages` 배포 환경에서 공개 주소와 배포 이력을 확인할 수 있습니다. 저장소 이름이 바뀌면 주소·QR을 다시 확인해야 합니다.

## 인쇄용 QR

공개 주소가 확정되기 전에는 QR 이미지를 만들지 않습니다. localhost·예시 도메인·임시 입력값은 생성 스크립트가 거부합니다.

```sh
node scripts/generate-qr.mjs
```

`site.json`의 `publicUrl` 대신 `--url` 뒤에 **실제 확정된 공개 HTTPS 주소**를 전달할 수도 있습니다. URL의 검색 매개변수와 해시는 넣지 마세요. 스크립트가 언어와 장소 경로를 추가합니다.

`public/qr/`에 메인 `main.png` / `main.svg`, 언어별 메인, 장소·언어별 PNG/SVG, 실제 연결 주소 목록 `manifest.json`을 생성합니다. 이미 빌드된 `dist/qr/`에도 복사합니다. 생성한 QR을 커밋하면 다음 배포에도 포함됩니다. PNG는 인쇄용 고해상도이고 SVG는 확대해도 선명합니다. 흰 여백을 자르거나 그림을 덧씌우지 말고 인쇄 전 Android·iPhone 카메라로 스캔해 공개 사이트와 해당 장소가 열리는지 확인하세요. QR 이미지 생성 자체가 URL의 접속 가능성을 보장하지는 않습니다.

## 공개 전 확인

- 원본 PDF와 4일 일정·방문 순서·집합 시간 대조

- 작은 모바일 화면, 큰 글자 설정, 키보드 사용 시 읽기·버튼 동작
- 실제 MP3 등록 후 재생·일시정지·진행바·속도·페이지 이동·오프라인 저장
- NAVER 지도 검색 결과·길찾기·정확한 집합 안내
- 체크리스트 선택 후 새로고침과 언어 전환 시 유지

행사 종료 후에는 `event.json`의 행사 공지와 소개를 관광 안내에 맞게 고치고 장소·오디오를 유지해 재사용할 수 있습니다. 체크리스트와 언어 선택은 각 브라우저의 로컬 저장소에 보관되며 서버에 전송하지 않습니다.

쇼핑 페이지는 `#/shopping`이며, 메인 메뉴와 11월 10일 일정에서 이동합니다. 일정 데이터와 동선은 유지했으며 일반 브라우저 뒤로가기로 원래 일정에 돌아갈 수 있습니다. 한국어·영어·간체·번체를 지원하고 언어 전환 시 해시 경로와 카테고리를 유지합니다. 기존 장소·일정에도 영어를 추가했습니다.

대전근현대사전시관 페이지는 `#/place/daejeon-modern-history`입니다. `이곳에서 촬영된 작품 / Filmed Here`의 카드가 작품별 장면 모달을 엽니다. 좌우 화살표·키보드·모바일 스와이프로 전환하고 사진을 누르면 전체 화면으로 확대합니다. 전체 화면이 지원되지 않는 브라우저는 화면 크기로 확대하며 X/Esc로 닫습니다.
